respR 使用指南 & resprpy 对照手册

水生态呼吸代谢分析：R 包 respR 2.3.4（Harianto & Carey 2019, Methods in Ecology and Evolution）的功能、用法，与 Python 移植版 resprpy 的逐项对照。resprpy 的数值输出与 R 完全一致（56 项对拍测试全绿）。

总览与流程 导入 检查 数据工具 手动速率 自动速率 背景校正 筛选 单位换算 临界氧 线性检验 绘图 完整流程 对象结构 已知差异

一、总览与分析流程

respR 是 R 生态中处理呼吸代谢（respirometry）数据的标准包：导入仪器数据、检查质量、计算耗氧率（MO₂）、做背景校正、单位换算、筛选结果、估计临界氧张力（Pcrit/O₂crit）。resprpy 是它的完整 Python 移植（GPL-3），27 个导出函数一一对应，数值与 R 实测输出逐位一致，可用于脱离 R 环境的独立分析（如桌面应用打包）。

数据文件→ import_file→ inspect→ calc_rate / auto_rate→ adjust_rate→ convert_rate→ select_rate→ oxy_crit→ 结果

二、数据导入 import_file

读取各种呼吸仪软件导出的原始文件（Witrox、NeoFox、AutoResp、Pyro 等 14 种格式），自动识别表头与单位。

R 
library(respR)
dat <- import_file("Witrox_eg.txt")
# $dataframe 为原始数据表
Python 
import resprpy as p
dat = p.import_file("Witrox_eg.txt")
# dat["dataframe"] 为原始数据表
备注：R 的 fread 会把某些 tab 分隔文件误拆成多列（R 自身的解析缺陷）；resprpy 的解析器更严格，逐值对拍以 R 能正确解析的样本（NeoFox）为基准，最大误差 0.0。

三、数据检查 inspect

检查数据质量：时间递增性、氧浓度范围、缺失值、重复值、序列异常等 6 项 QC 检查，并标注问题行的位置。

R 
res <- inspect(dat, time = 1, oxygen = 2,
              width = 0.1)
res$checks   # 检查结果表
res$locs     # 问题行位置
Python 
res = p.inspect(dat, time=1, oxygen=2,
                width=0.1)
res["checks"]   # 检查结果表
res["locs"]     # 问题行位置

inspect.ft() / inspect_ft() 用于流水式（flowthrough）数据：同时检查入水口、出水口氧浓度及其差值（delta）。

四、数据工具

format_time — 时间字符串解析

R 
format_time("2024-01-01 12:30:45",
            format = "ymdHMS")
Python 
p.format_time("2024-01-01 12:30:45",
              format="ymdHMS")

支持 ymdHMS、dmyHMS、HMS 等格式；返回数值秒数（resprpy 与 R 一样采用秒差+1 的起点约定）。

subsample / subset_data — 抽样与子集

R 
subsample(dat, n = 100)          # 均匀抽 100 行
subsample(dat, length.out = 50)  # 每 50 行抽 1
subset_data(dat, from = 10, to = 90,
            by = "time")         # 时间区间
Python 
p.subsample(dat, n=100)
p.subsample(dat, length_out=50)
p.subset_data(dat, from_=10, to=90, by="time")

sim_data — 模拟数据

R 
sim_data(len = 300, type = "default",
         sd = 0.05)
Python 
p.sim_data(len=300, type="default", sd=0.05)

生成带已知斜率的模拟耗氧序列，用于测试流程；test_lin() 用它检验自动速率计算的准确性。

五、手动速率计算

calc_rate — 指定区间回归

在原始数据上按 from/to（时间或行号）选定窗口做线性回归，得斜率（耗氧率）、截距、R² 及端点值。

R 
cr <- calc_rate(dat, from = 10, to = 90,
                by = "time")      # by = "row" 按行
cr$rate        # 速率值
cr$summary     # 回归详情表
cr$subsets     # 各区间的原始数据
Python 
cr = p.calc_rate(dat, from_=10, to=90,
                 by="time")
cr.rate        # 速率值
cr.summary     # 回归详情表 (dict)
cr.subsets     # 各区间的原始数据

calc_rate.int — 自动分段区间

按"预热-测量"循环自动分段：starts（起始行/时间）、wait（等待）、measure（测量时长），适合间歇式呼吸实验。

R 
calc_rate.int(dat, starts = 30,
              wait = 5, measure = 20,
              by = "row")
Python 
p.calc_rate_int(dat, starts=30,
                wait=5, measure=20,
                by="row")

calc_rate.bg — 空白背景速率

对空白（无动物）数据计算背景耗氧，供 adjust_rate() 使用。参数与 calc_rate 一致（默认全程回归）。

calc_rate.ft — 流水式速率

R 
calc_rate.ft(oxy_in, oxy_out,
             flowrate = 2,  # L/h 等
             by = "time", width = 10)
Python 
p.calc_rate_ft(oxy_in, oxy_out,
               flowrate=2, by="time",
               width=10)

用入水/出水氧浓度差 × 流速计算代谢率；width 是滚动窗口宽度。

六、自动速率计算 auto_rate

自动扫描所有可能的窗口并选出最优速率，6 种方法：

method含义
linear滚动回归中 R² 最高（结合核密度峰）
lowest / highest最低/最高速率（按绝对值语义）
minimum / maximum数值最小/最大速率
rolling滚动窗口回归的全程扫描
interval指定等长区间
R 
ar <- auto_rate(dat, method = "linear",
                width = 10, by = "row")
ar$rate       # 自动选出的速率
ar$summary    # 结果表（含 rank/row/endrow）
ar$density    # 核密度估计
ar$peaks      # 密度峰
Python 
ar = p.auto_rate(dat, method="linear",
                 width=10, by="row")
ar.rate
ar.summary    # dict
ar.density    # (x, y) 元组
ar.peaks
数值一致性：auto_rate 全链（滚动回归、bw.SJ 带宽、核密度、峰检测）与 R 逐位一致；density 512 点最大相对差 2e-13。

七、背景校正 adjust_rate

6 种校正方法：value（常数）、mean（背景均值）、paired（成对）、concurrent（并行空白）、linear（线性插值）、exponential（指数插值）。

R 
adj <- adjust_rate(cr, by = -0.0002,
                   method = "value")
adj <- adjust_rate(cr, by = bg,      # calc_rate.bg 对象
                   method = "mean")
adj$summary$rate.adjusted  # 校正后速率
Python 
adj = p.adjust_rate(cr, by=-0.0002,
                    method="value")
adj = p.adjust_rate(cr, by=bg, method="mean")
adj.summary["rate.adjusted"]

八、结果筛选 select_rate

34 种筛选方法，分四类：

  • 数值筛选：lowest/highest/minimum/maximum（n 个）、*_percentile（百分位）、rate（区间）、zero/nonzero/positive/negative
  • 时间/行号筛选：time/time_omit、row/row_omit、duration、oxygen/oxygen_omit
  • 索引筛选：rank/rank_omit、rep/rep_omit、manual/manual_omit
  • 重排序：rolling（按行）、intercept/slope/rsq（按统计量）、density/linear（按密度，仅 auto_rate linear 对象）
R 
cv <- convert_rate(cr, ...)      # 输入须为 convert_rate 对象
sr <- select_rate(cv, "highest", n = 3)
sr <- select_rate(cv, "rate", n = c(-0.1, 0.1))
sr$summary       # 筛选后的结果
sr$original      # 未筛选的原对象
Python 
cv = p.convert_rate(cr, ...)
sr = p.select_rate(cv, "highest", n=3)
sr = p.select_rate(cv, "rate", n=[-0.1, 0.1])
sr.summary
sr.original
R 对象语义：select_rate 返回副本，输入对象不变（resprpy 同样如此）。R 的 density/linear 只接受 auto_rate linear 对象、rep 系需要 rep 值——两者报错行为也一致。

九、单位换算

convert_rate — 完整换算链

把速率从"氧单位/时间单位"换算到目标单位，可附加体积（→ 绝对耗氧）、质量/面积（→ 比速率），并按 S/t/P 校正溶解氧。

R 
cv <- convert_rate(cr,
  oxy.unit = "mg/L", time.unit = "sec",
  output.unit = "mg/h/kg",
  volume = 0.1, mass = 0.01)
cv$rate.output   # 换算后速率
Python 
cv = p.convert_rate(cr,
  oxy_unit="mg/L", time_unit="sec",
  output_unit="mg/h/kg",
  volume=0.1, mass=0.01)
cv.rate_output

convert_DO / convert_MR / convert_val — 基础换算

函数用途
convert_DO(x, from, to, S, t, P)溶解氧浓度单位：mg/L、%Air、%O₂、kPa、hPa、torr、umol/L、mL/L 等，物理常数来自 marelac（solubility/摩尔体积/密度），可指定盐度 S、温度 t、气压 P
convert_MR(x, from, to, ...)代谢率单位（含时间维度：per sec/min/hr/day）
convert_val(x, from, to)任意数值单位转换（长度、质量、体积、压力…）
数值一致性：6 个物理锚点全中（如 sw_dens=1024.64077347883、molvol=24.03038425、mg/L→%Air=108.4419），逐值对拍 ≤1e-12。

十、临界氧张力 oxy_crit

估计临界氧张力（Pcrit / O₂crit）——耗氧率开始随环境氧下降的转折点，两种方法：

  • bsr（默认）：断棒回归（Yeager & Ultsch 1989），给出截距法与中点法两个估计
  • segmented：分段回归（Muggeo 2003，R segmented 包算法，含 bootstrap-restart 随机搜索）
R 
oc <- oxy_crit(dat, method = "bsr",
               width = 0.1)
oc$crit        # list(intercept, midpoint)
oc$summary     # 断棒结果
oc2 <- oxy_crit(dat, method = "segmented")
oc2$crit       # 断点值
Python 
oc = p.oxy_crit(dat, method="bsr", width=0.1)
oc["crit"]     # dict(intercept, midpoint)
oc["summary"]
oc2 = p.oxy_crit(dat, method="segmented")
oc2["crit"]
数值一致性：segmented 法完整移植了 R 的 MT19937 随机引擎（set.seed 序列逐位一致），bootstrap-restart 10 次重抽样与 R 结果逐位相同（crit=7.719111…）。

十一、线性检验 test_lin

用已知斜率的数据测试 auto_rate 的检测准确度：生成模拟数据 → 自动测速 → 对比真实斜率，输出回归统计。

R 
test_lin(reps = 1, len = 300,
         sd = 0.05, type = "default")
Python 
p.test_lin(reps=1, len_=300, sd=0.05,
           type="default", seed=None)
差异：R 的随机数据由 R 原生 RNG 生成；resprpy 内置了 R 的 MT19937（逐位一致），但 sim_data 的噪声路径与 R 内部调用顺序不完全相同，统计结果结构一致、个别随机样本值不可逐值比。

十三、完整流程示例（间歇式呼吸）

R 
library(respR)

# 1. 导入并检查
dat <- import_file("fish.txt")
ins <- inspect(dat, time = 1,
               oxygen = 2)

# 2. 自动分段计算速率
cr <- calc_rate.int(ins,
    starts = 30, wait = 5,
    measure = 20, by = "row")

# 3. 背景校正（空白对照）
bg <- calc_rate.bg(bg_dat)
adj <- adjust_rate(cr, by = bg,
    method = "mean")

# 4. 单位换算
cv <- convert_rate(adj,
    oxy.unit = "mg/L",
    time.unit = "sec",
    output.unit = "mg/h/kg",
    volume = 0.1, mass = 0.01)

# 5. 筛选最高速率
sr <- select_rate(cv, "highest", n = 3)

# 6. 临界氧分析
oc <- oxy_crit(fish_po2_data,
    method = "segmented")

# 7. 绘图
plot(cr); plot(sr)
Python 
import resprpy as p

# 1. 导入并检查
dat = p.import_file("fish.txt")
ins = p.inspect(dat, time=1, oxygen=2)

# 2. 自动分段计算速率
cr = p.calc_rate_int(ins,
    starts=30, wait=5, measure=20,
    by="row")

# 3. 背景校正（空白对照）
bg = p.calc_rate_bg(bg_dat)
adj = p.adjust_rate(cr, by=bg,
    method="mean")

# 4. 单位换算
cv = p.convert_rate(adj,
    oxy_unit="mg/L", time_unit="sec",
    output_unit="mg/h/kg",
    volume=0.1, mass=0.01)

# 5. 筛选最高速率
sr = p.select_rate(cv, "highest", n=3)

# 6. 临界氧分析
oc = p.oxy_crit(fish_po2_data,
    method="segmented")

# 7. 绘图
p.plot_calc_rate(cr)
p.plot_oxy_crit(oc)
