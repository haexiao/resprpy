1. Overview & Analysis Workflow

respR is the standard R package for respirometry data: import instrument files, quality-check them, compute oxygen uptake rates (MO₂) manually or automatically, correct for background respiration, convert units, select results, and estimate critical oxygen tension (Pcrit / O₂crit). resprpy is its complete Python port (GPL-3): all 27 exported functions, numeric outputs verified element-by-element against R 4.5.3 — suitable for standalone/desktop use without an R runtime.

data file→ import_file→ inspect→ calc_rate / auto_rate→ adjust_rate→ convert_rate→ select_rate→ oxy_crit→ results

2. Import — import_file

Reads raw files exported by respirometry software (Witrox, NeoFox, AutoResp, Pyro etc. — 14 formats), auto-detecting headers and units.

R 
library(respR)
dat <- import_file("Witrox_eg.txt")
# $dataframe: raw data table
Python 
import resprpy as p
dat = p.import_file("Witrox_eg.txt")
# dat["dataframe"]: raw data table
Note: R's fread mis-parses some tab-separated files into extra columns (an R-side defect); resprpy's parsers are stricter. Numeric parity is verified on samples R parses correctly (NeoFox, max error 0.0).

3. Data inspection — inspect

Quality checks: time increments, oxygen range, missing values, duplicates, sequential anomalies (6 QC checks), reporting the locations of problem rows.

R 
res <- inspect(dat, time = 1,
               oxygen = 2, width = 0.1)
res$checks   # QC table
res$locs     # problem row locations
Python 
res = p.inspect(dat, time=1, oxygen=2,
                width=0.1)
res["checks"]
res["locs"]

inspect.ft() / inspect_ft() targets flowthrough data: checks inflow, outflow and their delta simultaneously.

4. Data utilities

format_time — time string parsing

R 
format_time("2024-01-01 12:30:45",
            format = "ymdHMS")
Python 
p.format_time("2024-01-01 12:30:45",
              format="ymdHMS")

Formats: ymdHMS, dmyHMS, HMS etc.; returns numeric seconds (resprpy keeps R's seconds+1 convention).

subsample / subset_data

R 
subsample(dat, n = 100)          # 100 evenly spaced rows
subsample(dat, length.out = 50)  # 1 in every 50
subset_data(dat, from = 10, to = 90,
            by = "time")         # time interval
Python 
p.subsample(dat, n=100)
p.subsample(dat, length_out=50)
p.subset_data(dat, from_=10, to=90, by="time")

sim_data — simulated data

R 
sim_data(len = 300, type = "default",
         sd = 0.05)
Python 
p.sim_data(len=300, type="default", sd=0.05)

Generates oxygen-consumption series with known slope, used by test_lin() to benchmark automatic rate detection.

5. Manual rate calculation

calc_rate — regression over specified interval

Fits a linear regression over the window defined by from/to (time or row) — gives slope (MO₂), intercept, R², and endpoint values.

R 
cr <- calc_rate(dat, from = 10, to = 90,
                by = "time")     # or by = "row"
cr$rate        # rate value(s)
cr$summary     # regression details
cr$subsets     # raw data of each window
Python 
cr = p.calc_rate(dat, from_=10, to=90,
                 by="time")
cr.rate
cr.summary     # dict
cr.subsets     # list of arrays

calc_rate.int — automatic interval segmentation

Segments data by flush–wait–measure cycles: starts, wait, measure — designed for intermittent-flow respirometry.

R 
calc_rate.int(dat, starts = 30,
              wait = 5, measure = 20,
              by = "row")
Python 
p.calc_rate_int(dat, starts=30,
                wait=5, measure=20,
                by="row")

calc_rate.bg — blank background rate

Computes background respiration from blank (animal-free) data, for use by adjust_rate(). Same arguments as calc_rate (defaults to the whole series).

calc_rate.ft — flowthrough rate

R 
calc_rate.ft(oxy_in, oxy_out,
             flowrate = 2,  # e.g. L/h
             by = "time", width = 10)
Python 
p.calc_rate_ft(oxy_in, oxy_out,
               flowrate=2, by="time",
               width=10)

MO₂ = inflow–outflow O₂ difference × flow rate; width is the rolling window.

6. Automatic rate calculation — auto_rate

Scans all possible windows and selects the best rate; 6 methods:

methodmeaning
linearhighest R² rolling regression (with kernel-density peaks)
lowest / highestlowest/highest rate (absolute-value semantics)
minimum / maximumnumerically smallest/largest rate
rollingfull rolling-window scan
intervalequal-length intervals
R 
ar <- auto_rate(dat, method = "linear",
                width = 10, by = "row")
ar$rate       # selected rate
ar$summary    # results (rank/row/endrow)
ar$density    # kernel density estimate
ar$peaks      # density peaks
Python 
ar = p.auto_rate(dat, method="linear",
                 width=10, by="row")
ar.rate
ar.summary    # dict
ar.density    # (x, y) tuple
ar.peaks
Parity: the whole auto_rate chain (rolling regression, bw.SJ bandwidth, kernel density, peak detection) matches R bit-for-bit; density 512-point max relative diff 2e-13.

7. Background adjustment — adjust_rate

6 methods: value (constant), mean (mean of blank), paired, concurrent (parallel blank), linear and exponential (interpolated blank).

R 
adj <- adjust_rate(cr, by = -0.0002,
                   method = "value")
adj <- adjust_rate(cr, by = bg,  # calc_rate.bg result
                   method = "mean")
adj$summary$rate.adjusted  # adjusted rate
Python 
adj = p.adjust_rate(cr, by=-0.0002,
                    method="value")
adj = p.adjust_rate(cr, by=bg, method="mean")
adj.summary["rate.adjusted"]

8. Result selection — select_rate

34 selection methods in four groups:

  • Numeric: lowest/highest/minimum/maximum (n), *_percentile, rate (interval), zero/nonzero/positive/negative
  • Time/row: time/time_omit, row/row_omit, duration, oxygen/oxygen_omit
  • Index: rank/rank_omit, rep/rep_omit, manual/manual_omit
  • Reorder: rolling, intercept/slope/rsq, density/linear (auto_rate linear objects only)
R 
cv <- convert_rate(cr, ...)   # input must be convert_rate
sr <- select_rate(cv, "highest", n = 3)
sr <- select_rate(cv, "rate", n = c(-0.1, 0.1))
sr$summary       # selected results
sr$original      # unselected input
Python 
cv = p.convert_rate(cr, ...)
sr = p.select_rate(cv, "highest", n=3)
sr = p.select_rate(cv, "rate", n=[-0.1, 0.1])
sr.summary
sr.original
R object semantics: select_rate returns a copy; the input object is never modified (resprpy behaves the same). R rejects density/linear on non-auto_rate-linear objects and rep methods without rep values — resprpy raises the identical errors.

9. Unit conversion

convert_rate — full conversion chain

Converts rates from oxygen/time units to a target unit, optionally applying volume (→ absolute MO₂), mass/area (→ specific rates), and S/t/P corrections for dissolved oxygen.

R 
cv <- convert_rate(cr,
  oxy.unit = "mg/L", time.unit = "sec",
  output.unit = "mg/h/kg",
  volume = 0.1, mass = 0.01)
cv$rate.output   # converted rates
Python 
cv = p.convert_rate(cr,
  oxy_unit="mg/L", time_unit="sec",
  output_unit="mg/h/kg",
  volume=0.1, mass=0.01)
cv.rate_output

convert_DO / convert_MR / convert_val — base converters

FunctionPurpose
convert_DO(x, from, to, S, t, P)Dissolved-oxygen units: mg/L, %Air, %O₂, kPa, hPa, torr, umol/L, mL/L… physics from marelac (solubility/molar volume/density), salinity S, temperature t, pressure P
convert_MR(x, from, to, ...)Metabolic-rate units (with time: per sec/min/hr/day)

Parity: physical anchors exact (sw_dens=1024.64077347883, molvol=24.03038425, mg/L→%Air=108.4419), ≤1e-12 element-wise.

10. Critical oxygen tension — oxy_crit

Estimates the critical oxygen tension (Pcrit / O₂crit) — the point where MO₂ starts to decline with ambient oxygen. Two methods:

  • bsr (default): broken-stick regression (Yeager & Ultsch 1989), reporting both intercept and midpoint estimates
  • segmented: piecewise regression (Muggeo 2003, the R `segmented` algorithm including its bootstrap-restart random search)
R 
oc <- oxy_crit(dat, method = "bsr",
               width = 0.1)
oc$crit        # list(intercept, midpoint)
oc$summary     # broken-stick results
oc2 <- oxy_crit(dat, method = "segmented")
oc2$crit       # breakpoint value
Python 
oc = p.oxy_crit(dat, method="bsr", width=0.1)
oc["crit"]     # dict(intercept, midpoint)
oc["summary"]
oc2 = p.oxy_crit(dat, method="segmented")
oc2["crit"]
Parity: the segmented method reproduces R's MT19937 RNG bit-for-bit (set.seed sequences identical); the 10-sample bootstrap-restart search matches R exactly (crit=7.719111…).

11. Linearity test — test_lin

Tests auto_rate detection accuracy with known-slope data: simulate → auto-detect → compare with truth, returning regression statistics.

R 
test_lin(reps = 1, len = 300,
         sd = 0.05, type = "default")
Python 
p.test_lin(reps=1, len_=300, sd=0.05,
           type="default", seed=None)
Difference: resprpy embeds R's MT19937 (bit-exact), but the noise-generation call sequence inside sim_data differs from R's internal call order, so statistics match in structure while individual random samples are not comparable value-by-value.

13. Complete workflow (intermittent-flow)

R 
library(respR)

# 1. import & inspect
dat <- import_file("fish.txt")
ins <- inspect(dat, time = 1,
               oxygen = 2)

# 2. automatic segmentation
cr <- calc_rate.int(ins,
    starts = 30, wait = 5,
    measure = 20, by = "row")

# 3. background correction
bg <- calc_rate.bg(bg_dat)
adj <- adjust_rate(cr, by = bg,
    method = "mean")

# 4. unit conversion
cv <- convert_rate(adj,
    oxy.unit = "mg/L",
    time.unit = "sec",
    output.unit = "mg/h/kg",
    volume = 0.1, mass = 0.01)

# 5. select best rates
sr <- select_rate(cv, "highest", n = 3)

# 6. critical oxygen
oc <- oxy_crit(fish_po2_data,
    method = "segmented")

# 7. plots
plot(cr); plot(sr)
Python 
import resprpy as p

# 1. import & inspect
dat = p.import_file("fish.txt")
ins = p.inspect(dat, time=1, oxygen=2)

# 2. automatic segmentation
cr = p.calc_rate_int(ins,
    starts=30, wait=5, measure=20,
    by="row")

# 3. background correction
bg = p.calc_rate_bg(bg_dat)
adj = p.adjust_rate(cr, by=bg,
    method="mean")

# 4. unit conversion
cv = p.convert_rate(adj,
    oxy_unit="mg/L", time_unit="sec",
    output_unit="mg/h/kg",
    volume=0.1, mass=0.01)

# 5. select best rates
sr = p.select_rate(cv, "highest", n=3)

# 6. critical oxygen
oc = p.oxy_crit(fish_po2_data,
    method="segmented")

# 7. plots
p.plot_calc_rate(cr)
p.plot_oxy_crit(oc)

14. Package structure comparison (respR vs resprpy)

respR is a standard R package: 33 source files under R/ and 16 imported packages (data.table, dplyr, marelac, roll, segmented, lubridate, xml2…), of which the rolling regression (roll), physics constants (marelac) and breakpoint regression (segmented) are separate C/C++ packages. resprpy is a pure-Python package: 19 modules under src/resprpy/, depending only on numpy/scipy (plus optional matplotlib for plots); every underlying algorithm is inlined — no C/C++ runtime.
